# ingestor

Runs N connectors concurrently, archives raw payloads to Garage, normalizes to canonical events, publishes to NATS, writes market data to VictoriaMetrics, keeps reference data and run bookkeeping in Postgres.

**Status:** implemented (v1) — connectors are supervised and can be started/stopped/enabled/disabled at runtime over `ctl.ingest.*`; health, gap and unresolved frames on `ingest.*` with source halts on `risk.halt.source:<id>`; backfill jobs from the `JOBS_INGEST` work queue (D-054); envelopes are routed and published; trades, quotes, bars and books are batched into VictoriaMetrics; raw payloads go to Garage (`-garage`); symbols resolve through Postgres with provisioning of unknown ones, cursors and `ingest.connector_run` rows (`-postgres`); secrets from `config/secrets.toml` / env (`-secrets`, D-020); per-source limiter; heartbeat counters; graceful shutdown. Live connectors: `heartbeat`, `yahoo`, `hackernews`, `google_news`; keyed: `lemon`, `oanda`.

## Implemented
- **Supervisor** (`supervisor.go`): starts a connector by source id when it is registered (`go/connectors/*`) and its catalog status is not `disabled`/`planned` (the synthetic `heartbeat` is allowed without a catalog entry). Stops cancel the connector's context and wait for it to exit.
- **Control** (request/reply with `CtlRequest`/`CtlReply`, spec 10 §4.3): `ctl.ingest.start` / `ctl.ingest.stop` (arg `source`); `ctl.ingest.enable` / `ctl.ingest.disable` (arg `source`) persist `catalog.source.status` (`live` / `disabled`) through `refdata.Store.SetStatus`, update the in-memory catalog and start/stop the connector (a disabled source cannot be started until enabled; `enable` needs a registered connector); `ctl.ingest.backfill` (args `source`, `timescale`, `start`, `end`, `instruments` as a comma list) validates and enqueues a `jobs.ingest.backfill` job and replies with the job id; `ctl.ingest.status` replies with JSON `{running[], connectors[], health[] (current frames), cursors[] (ingest.backfill_cursor rows, with -postgres), limiters{source: {Saturation, Requests, Total, Window}}}`. Error messages are prefixed `not_found:` (unknown source / no connector), `conflict:` (already running, not running, blocked status, cannot backfill) or `invalid:` (bad args); control-api maps them to 404/409/400. The spec's per-source subject `ctl.ingest.<source_id>.<verb>` is replaced by the verb-only subject plus a `source` arg so it fits `bus.Ctl(service, verb)`.
- **Status precedence** (spec 11 §8, D-054): `SyncCatalog` upserts the YAML but keeps an existing row's `status`; the ingestor then applies `catalog.source.status` to its in-memory catalog (`Catalog.ApplyStatuses`). So the YAML `status` only seeds new rows; after the first sync Postgres wins, and `-connectors` entries whose DB status is `disabled` are not started. Without `-postgres`, enable/disable only change the in-memory catalog.
- **Health** (`health.go`, spec 10 §6.7, spec 21 §4.1): the `Tracker` publishes one JSON frame per running connector on `ingest.health.<source>` every 5 s: `status` (`ok` | `degraded` | `down`), `running`, `mode` (`stream`|`poll`), `expected_period_s` (poll interval, 30 s for streams), `last_activity_at/age_s` (last successful poll or stream message), `last_event_at/age_s` (last canonical event), `events_total`, `errors_total`, window counters (`window_s`, `events_window`, `errors_window`, `error_rate` = errors per minute), `limiter_saturation` (share of the window callers spent blocked in the source's token bucket, `connector.MeteredLimiter`), `limiter_requests`, `last_error`, `reason`, `halted`. Rules: no activity for 3 × expected period, or the connector exited on its own → `down`; any error in the window or limiter saturation > 0.8 → `degraded`. A source that goes `down` unexpectedly raises `Halt{scope:"source:<id>", manual:false}` on `risk.halt.source:<id>` (D-042 family `source`, qualifier after the colon — `fa_risk::HaltScope::parse` maps it to `HaltScope::Source`; note the risk-engine keeps one halt per family, so a resume of any source clears the family) and publishes `risk.resume.source:<id>` once it is healthy again; operator stops (`ctl.ingest.stop|disable`) publish a final `down` frame with `running:false` and no halt. Payloads are JSON rather than a proto because `fa.v1` has no health message and `Heartbeat` only carries numeric counters (control-api mirrors the frames into `GET /api/sources`).
- **Gaps and unresolved symbols:** `ingest.gap.<source>` JSON `{source, instrument_id, timeframe, from, to, missing_periods, at}` when consecutive live bars of one instrument/timeframe are more than one period apart; the detector is seeded from the persisted live cursors so the first bar after a restart is checked against the cursor too (calendar-aware suppression of overnight gaps is pending). `ingest.unresolved.<source>` JSON `{source, venue_symbol, instrument_id?, reason, at}` when the resolver provisions an instrument (D-050; via `refdata.Resolver.OnProvision`) or a connector reports a symbol it could not resolve. Poll failures no longer end the connector: `pollLoop` records the error (health `degraded`) and retries with exponential backoff capped at the poll interval.
- **Backfill work queue** (`backfill.go`, spec 10 §6.4, spec 21 §5): `bus.EnsureWorkQueue(ctx, js, "ingest", "ingestor")` creates `JOBS_INGEST` on `jobs.ingest.>` with the durable pull consumer `ingestor` (ack wait 60 s, max deliver 5). Jobs are `fa.v1.Job{kind: "ingest.backfill", spec: JSON {source, instruments?: [symbols], timescale, start?, end?}}`; `end` defaults to now and `start` to `end − depth(timescale)` with spec 10 §3 depths (`catalog.BackfillDepth`: seconds 4 w, minutes 1 y, hours 5 y, days 50 y); `instruments` default to the catalog `config.symbols` (text sources run one query with no symbol). One job runs at a time, in a fresh connector instance that shares the live connector's token bucket (one `MeteredLimiter` per source), publishing `JobProgress` on `jobs.progress.<job_id>` per instrument and `JobResult` on `jobs.result.ingest.backfill` with result JSON `{source, timescale, start, end, events, instruments: [{symbol, instrument_id, events, cursor, status: done|skipped|failed, error?}]}`. Idempotency: every `(source, instrument, timescale, range_start)` has its own `ingest.backfill_cursor` row (`refdata.BackfillCursors`); a redelivered or re-enqueued range resumes from `cursor` and a `done` range is skipped; in-progress acks every 20 s keep the ack window open, a shutdown mid-job NAKs for redelivery. Each job also writes an `ingest.connector_run` row (`running` → `done`|`failed`). Verified live 2026-11-10: a 1-day 1m AAPL job produced 782 envelopes (392 bars) into VictoriaMetrics in 80 ms; the same range re-enqueued finished with 0 events.
- **TSDB writer** (`go/pkg/tsdb`): every published market envelope becomes samples at `event_time` (spec 20 §5.3): `fa_trade_{price,size}`, `fa_quote_{bid,ask}_{px,sz}`, `fa_bar_{open,high,low,close,volume,vwap}{tf}`, `fa_book_*{lvl}`, labels `inst,venue,src`; batched (500 points or 1 s) into `POST <tsdb-url>/api/v1/import`. Buffer is bounded (50 000 points) and drops when VictoriaMetrics is unreachable.
- **Raw archive** (`go/pkg/archive`): with `-garage`, every `RawMessage` is appended to a per-source, per-minute gzip object `raw/<source>/<yyyy>/<mm>/<dd>/<hh>/<ulid>.raw.gz` in bucket `fa-raw` and the envelopes carry `raw_ref{key, offset, length}` (offsets into the decompressed object). Credentials: `[garage]` in `config/secrets.toml` or `FA_GARAGE_ACCESS_KEY_ID` / `FA_GARAGE_SECRET_ACCESS_KEY`. Without `-garage`: `NopArchive`.
- **Reference data** (`go/pkg/refdata`): with `-postgres`, the catalog is synced into `catalog.source`, symbols resolve through `ref.listing`/`ref.identifier`, unknown `(source, symbol)` pairs are provisioned as `status='provisional'` instruments with a deterministic UUIDv5 plus an open `ingest.quarantine` row, every connector start/stop writes `ingest.connector_run`, and connectors persist progress in `ingest.backfill_cursor`. Without `-postgres`: in-memory `StaticResolver` (empty, so market connectors report everything unresolved) and in-memory cursors.
- **Secrets** (`go/pkg/connector`): `-secrets` file (`[sources.<id>]`), `FA_<SOURCE>_<KEY>` env overrides; passed to connectors as `SourceConfig.Secrets`.
- **Heartbeat counters:** `connectors.running`, `connectors.up.<id>` (0/1 for every registered connector), `events.<id>`, `errors.<id>`, `unresolved.<id>`, `provisioned.<id>`, `backfill.enqueued|done|failed`, `tsdb.written|errors|dropped`, `archive.messages|objects|errors`, `refdata.errors`.

## Run
```sh
# host, after `just go-build` (binaries land in go/bin)
go/bin/ingestor -nats nats://127.0.0.1:4222 -catalog config/sources.yaml -connectors heartbeat,yahoo,hackernews,google_news \
  -tsdb-url http://127.0.0.1:8428 -postgres postgres://fa:fa@127.0.0.1:5432/fa -garage http://127.0.0.1:3900 -secrets config/secrets.toml
```
| Flag | Env | Default | |
|---|---|---|---|
| `-nats` | `FA_NATS_URL` | `nats://127.0.0.1:4222` | |
| `-catalog` | `FA_CATALOG` | `config/sources.yaml` | |
| `-connectors` | `FA_CONNECTORS` | `heartbeat` | comma list started at boot; `""` starts nothing (use `ctl.ingest.start`) |
| `-tsdb-url` | `FA_TSDB_URL` | `http://127.0.0.1:8428` | VictoriaMetrics base URL; `""` disables the writer. In compose use `http://victoriametrics:8428` |
| `-postgres` | `FA_POSTGRES_URL` | `""` | Postgres URL; enables the `refdata` resolver, cursors and run log. Compose: `postgres://fa:fa@postgres:5432/fa` |
| `-garage` | `FA_GARAGE_URL` | `""` | Garage S3 endpoint; enables the raw archive. Compose: `http://garage:3900` |
| `-secrets` | `FA_SECRETS` | `config/secrets.toml` | secrets file; missing file is fine when env vars carry the keys |
| `-heartbeat` | | `5s` | |

Start/stop from the control API: `curl -X POST http://127.0.0.1:7700/api/ingest/heartbeat/stop`; enable/disable/backfill: `POST /api/sources/{id}/enable|disable|backfill` (backfill body `{instruments, timescale, start, end | range}`), job status at `GET /api/jobs?kind=ingest.backfill`, health at `GET /api/sources/{id}`. Check the series: `curl 'http://127.0.0.1:8428/api/v1/series?match[]=fa_bar_close'` (VictoriaMetrics hides the last 30 s by default, `-search.latencyOffset`). Provisioned instruments: `select * from ingest.quarantine`; runs: `select * from ingest.connector_run order by started_at desc`.
