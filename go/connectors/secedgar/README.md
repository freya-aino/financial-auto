# secedgar

SEC EDGAR filings via the submissions API, catalog id `sec_edgar`. No key; a declared User-Agent is required.

**Status:** implemented; verified 2026-11-11 (`data.sec.gov/submissions/CIK0000320193.json` → 200 with UA `financial-auto ingestor`, 403 "Undeclared Automated Tool" with the ingestor's generic UA).

## Behaviour
- **Config:** `config.extra.ciks` (comma list; default `320193,789019`, the catalog lists 5; backfill jobs may name a CIK as their instrument, which the ingestor does not resolve into a `ref` instrument because the source has no venue), `config.extra.user_agent` or secret `[sources.sec_edgar] user_agent` / `FA_SEC_EDGAR_USER_AGENT` (default `financial-auto ingestor`), `config.extra.lookback` (default `168h`).
- **Poll** (every 10 minutes): one submissions document per CIK (catalog `rate_limit` 2/s, burst 4). With `-postgres` the ingestor writes filings to `wh.filing` (idempotent on `(source_id, accession)`).
- **Normalize:** each `filings.recent` entry → `FilingEvent` on `filing.event.sec_edgar`: `issuer_cik` (10 digits), `issuer_lei` (when EDGAR has one), `form_type`, `accession`, `filing_time = acceptanceDateTime` (UTC), `document_refs = [https://www.sec.gov/Archives/edgar/data/<cik>/<accession without dashes>/<primaryDocument>]` (the `-index.htm` page when no primary document). `event_time = publish_time` = acceptance time; without one, event = filingDate 00:00 ET and publish = filingDate 22:00 ET (conservative, EDGAR's last acceptance for that date). No instrument id.
- **De-dup:** accession set in memory plus a per-CIK cursor (`ingest.backfill_cursor`, scope `cik:<cik>`) = newest acceptance published. A first run without a cursor only emits filings accepted within `lookback` so the ~1000 historical entries are not replayed live.
- **XBRL company facts → `wh.fundamental`** (`facts.go`): `data.sec.gov/api/xbrl/companyfacts/CIK##########.json` per CIK, fetched inside Poll (shared limiter and UA) at start and every `extra.facts_interval` (default `6h`, `off` disables). Only whitelisted concepts (`extra.facts_concepts`, `<taxonomy>:<concept>` comma list; default 17 us-gaap/dei concepts in `DefaultConcepts`) become `FundamentalFact` envelopes on `filing.fact.sec_edgar` (stream TEXT): `field = taxonomy:concept`, `unit`, `period = <start>..<end>` (duration) or `<end>` (instant) — the fact's own period; the filing's `fy`/`fp` are kept as `fiscal_year`/`fiscal_period` because a 10-K restates earlier years —, `vintage = publish_time = filed` date 22:00 ET (`publish_time_estimated`), `event_time` = period end, `form`, `accession`. Cursor scope `facts:<cik>` = newest vintage published (facts with an older vintage are skipped; the first run emits the whole history, ~3 000 facts per CIK). The ingestor's warehouse writer inserts them idempotently (natural key CIK, field, unit, period, vintage, source; revisions are new vintages); `instrument_id` is set only when exactly one instrument carries the CIK in `ref.identifier` (scheme `cik`).
- **Backfill:** the same document filtered to `[From, To)` on acceptance time, for the job's CIK or all configured CIKs; older pages (`filings.files[]`) are fetched when their date span overlaps the range.
