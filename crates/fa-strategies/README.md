# fa-strategies

Strategy population: GP programs and neural policies producing exposure distributions.

**Status:** implements spec 35 §4.2–§4.3 / §6.3 / §6.5 for both representations — GP DSL AST + interpreter (the full §4.2 set: graph / decoder / portfolio primitives incl. `exposure_gross` / `drawdown`, `clip`, `Bool` comparisons with `if`, `prob_gt`), `GpStrategy`; **neural policies** (`neural::PolicyNet` MLP, `NeuralStrategy`, text form with exact weights, ES / topology / input-mask variation; candle SGD fine-tune behind feature `train`); S-expression syntax (`sexpr`); `strategies.toml` population files (GP or `policy` entries, `assets`) and the hand-written **baseline** set; the live observation `features::LiveContext` (real latent graph + decoder outputs + latent means with price-only fallbacks and per-source counters, strategy-level `PortfolioSummary`); the point-in-time latent graph `graph::LatentGraph` (states per snapshot, parallel snapshots readable with `at_snapshot`); the decoder-output cache; the **strategy genome** (representation, asset set, snapshot binding), typed random programs (region literals for bound genomes) and neural immigrants (`random`), the typed GP operators (`ops`), **asset-set mutation** over MCMC pair proposals (`assets`), region-literal remapping (`remap`); `op_cost`, the representation-independent compute unit of the `compute_cost` objective (all tested).

## DSL (`sexpr`)
Grammar `atom | (op arg...)`; operators `add sub mul div neg tanh min max if_gt clip if`; `Bool` forms `gt lt and or not` (only as an `if` condition; a program must be `Num`); `(prob_gt (fc_dist k)|(analog_outcome k) x)`.

| Type | Forms |
|---|---|
| `Region` | `(cur_region expert)`, literal `(region expert ordinal)` (region `<prefix>-e<expert>-r<nnn>` of the strategy's bound `snapshot`) |
| `RegionSet` | `(neighbors r n)` |
| `[Path]` | `(sample_walk r k n)` |
| `Num` (graph, spec 33) | `stay_prob`, `(path_up k)`, `region_entropy`, `(p_trans a b k)`, `(p_to_set r S k)`, `(hitting_time r S)`, `(dwell r)`, `(novelty expert)`, `(region_feature r mass\|mean_fwd_return\|vol)`, `(path_value (sample_walk r k n) up\|mass\|mean_fwd_return\|vol)` |
| `Num` (decoders, spec 34) | `(quantile q)`, `analog_forecast`, `(score family)`, `(fc_quantile q k)`, `(fc_dist k)`, `(analog_outcome k)`, `analog_age`, `(text_score topic)`, `(visual_score kind)` |
| `Num` (portfolio) | `position`, `unrealised_pnl`, `time_in_trade`, `exposure_gross`, `drawdown` |

Typed forms are only valid as arguments (`(add (cur_region 0) 1)` is a `ParseError::Type`); arities are checked. The asset of the decoder primitives is the instrument being evaluated. `(score family)` takes dotted family names (`(score text.news)`); `(text_score topic)` / `(visual_score kind)` take a bare word. `Display` round-trips (`parse(&e.to_string()) == e`).

Evaluation is total: a non-finite node value becomes 0. `fa_strategies::take_non_finite()` returns (and resets) how many such replacements happened on the calling thread, which the runtime reads around a step to apply spec 35 §8 (NaN → 0 exposure, repeated → auto-pause).

## Live observation (`features::LiveContext`)
Wraps the price-only `FallbackContext` and, when given, a `graph::GraphAt` view (one timescale, fixed at the step time) and a `decoders::DecodersAt` view (one instrument, recency window). Each primitive answers from the first source with data and counts the source (`Sources { graph, decoder, fallback }`), which `bins/strategy-runtime` sums into its heartbeat (`primitives.graph|decoder|fallback`); `primitive_sources()` names the primitives per source (the runtime's `starved` flag). `with_bar(ts)` sets the unit of decoder `k` arguments. `analog_outcome` reports the analogs it could not price (`take_analog_requests()`) and those it priced (`take_analog_resolved()`) so a caller can prefetch prices. Point-in-time: views only see messages with event time ≤ the step. The fallback table is in the module docs.

## Latent graph (`graph::LatentGraph`)
Fed with `LatentState` (per-instrument region per expert, posterior std, history → `cur_region`, `dwell`, `novelty`, occupancy), `RegionEvent` (registry: lineage, `live|merged|split|retired`), `TransitionUpdate` (bounded **versions** of each row's posterior mean + 90 % interval) and realised bar closes (`record_close` → per-region return statistics for `region_feature`). `GraphAt` rebuilds each expert space's kernel as an `fa_mcmc::MarkovGraph` from the summaries as of the view time (`set_row_from_summary` recovers the Dirichlet concentration from the interval), so `p_trans(a, b, k)` is the matrix power of the posterior-mean kernel (`TransitionMatrix::k_step`), `neighbors` ranks by mass, `sample_walk` / `hitting_time` / `path_value` use posterior-predictive walks seeded from `(timescale, expert, region, k, n, at_ms)` (deterministic per step).

## Decoder outputs (`decoders::DecoderOutputs`)
`decoder.output.<family>` keyed by `(exact family, instrument)` (instrument from `output_refs` `inst:<uuid>`; `inst:*` or no `inst:` ref = market-wide; the additive `DecoderOutput.instrument_id` field (D-098) feeds control-api's store and is not read here), bounded, event-time ordered; every query is point-in-time (`as_of ≤ t`) within a recency window, and a fresh instrument-specific output always wins over a market-wide one.

| Primitive | Source |
|---|---|
| `fc_quantile(q, k)`, `fc_dist(k)` | interpolated `rnn_prior` quantile vector (levels `0.05 0.25 0.5 0.75 0.95` for five values) / its mean, of the fresh output whose **horizon** is closest to `k` (ties → latest) |
| `analog_outcome(k)` | similarity-weighted realised `k`-bar log return after each `retrieval` analog's `window_end`, from a caller `PriceLookup`; only outcome windows completed at or before `t` count; `analog_outcome_detail` lists resolved / pending / unpriced analogs |
| `analog_age` | mean `time_distance_days` |
| `score(family)` | freshness `1 − age / max_age` of the latest output of that exact family |
| `text_score(topic)` / `visual_score(kind)` | `quantiles[0]` (clamped to `[-1, 1]`) of the latest fresh `text.<topic>` / `visual.<kind>` output (model-runtime: `text.news`, `text.summary`, `text.narrative`, `visual.chart`, `visual.future`); `None` → fallback 0 |

**Horizon.** `DecoderOutput` has no horizon field. `Output::horizon` is the `output_refs` entry `h:<steps>`, else `h=<n>` / `"h": n` in a `genome:<text>` ref or in `genome_id` when that is a decoder genome text (`forecast:h=3;lb=8`). evo-worker writes `output_refs = [inst:<uuid>, job:<id>, h:<horizon bars>]` (D-064) and model-runtime's neural serving adds `h:<horizon>` too, so the horizon is exact for both producers; with no known horizon the latest output wins (the pre-D-063 behaviour).

## Baselines (`baselines.toml`)
Hand-written, `genome_id = "baseline"`: momentum / reversion / path skew / quantile asymmetry / regime (price-era names), two graph programs (`baseline-graph-neighbors-1s`, `baseline-graph-regime-1m`) and two decoder-score programs: `baseline-text-visual-1s` (`(mul 3 (mul (text_score news) (visual_score future)))`, uncertainty `1 − (score text.news)`) and `baseline-narrative-chart-1m` (narrative + summary consensus gated by the chart score's sign). All evaluate in tests on price-only, synthetic-graph and synthetic text/visual decoder inputs.

## Genome, random programs, operators (`genome`, `random`, `ops`)
`genome::StrategyGenome` = spec genes (`timescale`, `steps`, `lookback_bars`, `step_secs`, optional `snapshot`) + the two programs + lineage (`parents`, `generation`). Its id is `gp-<16 hex>` of the phenotype (same programs and spec → same id, whatever the lineage; a `snapshot` binding is part of the phenotype, unbound genomes keep their ids). **Text form** = a `strategies.toml` entry: `to_string()` renders one TOML inline table on a single line (`{ id = "gp-…", genome_id = "gp-…", timescale = "1s", steps = 5, lookback_bars = 32, signal = "…", uncertainty = "…" }`) so genomes travel in the newline-separated `genomes` of `ctl.evo.start`; `parse` accepts that, a bare `key = value` body or a `[[strategy]]` entry; `to_toml_entry` / `population_toml` write the multi-line file the promoted `strategies.<generation>.toml` artifact uses. `parse(&g.to_string()).id() == g.id()`.

`random::RandomSpec` (depth / node limits, ERC range, `max_k`, experts, score families, `extended` = include the spec 35 §4.2 primitives) drives grow-method generation: every node is `Num`-typed, literal arguments (`k`, `q` from `LEVELS`, expert index, feature names, family / topic words) are drawn from their own domains, so every program parses back through `sexpr`. `random_genome` / `random_population(seed, n, timescale, spec)` produce immigrants.

`ops`: pre-order tree helpers (`subtree`, `replace`, `rebuild`, `depth`), `subtree_crossover` (node-limited), `point_mutation` (same-arity swap), `subtree_mutation`, `hoist_mutation`, `constant_jitter` (ERCs × `1 + σN`, quantile levels and `k` steps move to neighbours), `mutate_genome` (one tree mutation or a spec-gene mutation, lineage set) and `crossover_genome`. `OpKind::as_str` names the operator for Helix `ParentOf{op}` edges.

## Region remapping (`remap`)
`LineageBook` collects model-runtime's snapshot-swap lineage (`RegionLifecycleEvent` on `latent.lifecycle.<ts>`, `reason = snapshot`: ancestors `carry|split|merge|partial` with probe overlap; unmatched parents die). `remap_def` rewrites a bound strategy's literals into the new snapshot: a `carry` successor, else the successor with the largest overlap; no descendant or no observed lineage → unmappable (`RemapReport`). strategy-runtime swaps a fully mapped strategy in place and suspends an unmappable one; the risk-engine pipeline sends a remapped active strategy back to shadow. Random generation does not emit literals.

## Neural policies (`neural`)
`PolicyNet`: per-asset shared-weight MLP over a masked subset of 20 observation features (`FEATURES`: the GP primitives, scaled to ~[-1, 1]) and the first `latent_dims` (≤ 8) latent-mean dims of masked experts; 1–3 hidden layers (2–64, `tanh`/`relu`); `mean = tanh(o₀)`, `std = min(1, softplus(o₁))`. Text form `mlp:f=<hex>;e=<hex>;l=<n>;h=16x8;a=tanh;w=<base64 f32 LE>` (exact round trip; genome id `nn-<hash>`). Variation: `perturb` (ES), `mutate_topology` (widen with zero out-weights / narrow / insert identity layer / drop layer by composition), `mutate_inputs` (switch a feature or an expert's latents on with zero weights, or off), `crossover` (per-layer blend, same topology only). `train::fine_tune` (feature `train`, candle CPU): maximises `mean[ln(1 + L·m·r) − c·|Δm|] − w_s·mean(s − ŝ)²`, AdamW, newest 25 % held out, best held-out weights kept; `candle_forward` is pinned to the plain forward by a test. `flops()` / `op_cost` give `compute_cost` in one unit for both representations.

## Asset sets (`assets`)
`StrategyGenome::assets` (sorted instrument UUIDs; empty = every instrument) is part of the phenotype id. `mutate_assets` over `AssetProposals` (from `fa.v1.CrossAssetPriors`): unrestricted → a proposed pair ∝ score; add a partner ∝ pair support; remove the least-supported member (the last one → unrestricted); swap a member for a partner; at most `MAX_ASSETS` (8).

## Strategy model (lasting content of the retired spec 35)
Spec 35 was retired 2026-11-15 (every acceptance criterion met, every open question answered; last version in git history). Section numbers below follow the spec.

**Decisions (§3).** Neural policies and GP programs compete in one population under the same Pareto fitness; separate breeding pools share one NSGA-II front and `min_share_per_repr` keeps both representations alive. GP primitives operate on graph ops, decoder outputs and portfolio state — **no classic TA primitives**. A strategy's output is a **distribution over target exposure** per asset in its set (`mean ∈ [-1, 1]` of strategy capital, `std ∈ [0, 1]`; the allocator consumes the uncertainty), long + short within the caps enforced downstream. Strategies are multi-horizon with matched scope (lookback ≈ horizon scale) and declare their asset set (evolved or MCMC-proposed). Fitness is net of costs and corrected for multiple testing (deflated Sharpe / PBO); no walk-forward inside evolution; one locked-holdout use per strategy plus live paper shadow before promotion.

**Interface (§4.1).** `fa_strategies::Strategy { id, horizon, step(as_of_ms, assets: &[(InstrumentId, &dyn StrategyContext)]) -> ExposureDistribution, ops_per_asset, genome_id }`, implemented by `GpStrategy` (`mean = tanh(signal)`, `stddev = sigmoid(uncertainty)`) and `neural::NeuralStrategy`. The spec genes live in `population::StrategyDef` / `genome::StrategyGenome` (`StrategyDef::build_dyn` builds either representation). The bus message is `fa.v1.ExposureDistribution` (`proto/fa/v1/strategy.proto`) on `signal.exposure.<strategy_id>`, consumed by the meta-allocator in the risk-engine.

**Data model (§5).** Evolved strategies are Helix `Genome{kind: strategy, family: gp}` nodes written by the evo-worker; the risk-engine pipeline mirrors each one's lifecycle status from `ledger.strategy_state` onto its node every round (best-effort; Postgres is the source of truth — see the [risk-engine README](../../bins/risk-engine/README.md)). Hand-written baselines are not genomes and get no node. Neural weights travel in the genome text (a few KB), not Garage. Exposure intents are replayed from the retained `SIGNAL` JetStream stream (`fa_bus::replay`), not archived to Garage. Strategy virtual books and P&L live in the Postgres ledger and VictoriaMetrics series.

**Evaluation (§6.1).** `evo.eval.strategy` replays a genome through `fa_backtest::replay` with the recorded latent graph, decoder outputs and the shared cost model — same snapshot, deterministic given seed + window, every evaluation a `validation.trial` row. Fitness trades under the live cost-aware rule (`fa_backtest::trade_rule::TradeRule::CostAware`, parsed by evo-worker from the risk-engine's `risk.toml` and priced with `costs.yaml`): in the strategy replay the genome is the sole contributor of each sleeve, the turnover budget is against the whole replay capital, and `confirm_secs` is met by one bar when the bar is at least that long. `FA_EVO_TRADE_RULE=fraction` reproduces the old any-move rule; trials scored across the switch are not comparable. Event-time replays shift late-publishing sources by their catalog knowledge delay, so fitness never sees prices the live strategy could not.

**Fitness (§6.2, `fa_backtest::replay::DIRECTIONS`).** `deflated_sharpe` (max), `sharpe` (max), `max_drawdown` (min), `cvar` = CVaR(5 %) of daily returns as a positive loss (per step when the window spans < 20 days) (min), `turnover` (min), `cost_sensitivity` = Sharpe − Sharpe under 2× costs (min), `calibration` = corr(emitted std, next |return|) (max), `compute_cost` = log10 estimated operations per step via `op_cost` (min), `diversification` = mean correlation of the candidate's 64 block returns with the generation's current elites (min). PBO is estimated per generation over the candidate set; a generation with PBO > `pbo_max` (or unknown) promotes no one. The deflated-Sharpe implementation reproduces Bailey & López de Prado (2014)'s worked example.

**Evolution (§6.3).** `evo.vary.strategy` (protocol v1) splits the parents by representation and breeds each pool through `fa_evolution::vary::vary_with` — GP with `fa_strategies::ops`, neural with the `neural` operators — never across pools; the orchestrator's NSGA-II front stays shared. Pool sizes follow the parents' shares clamped to `[min_share_per_repr, 1 − min_share_per_repr]`; a pool without parents is refilled with random immigrants of its representation, plus `immigrant_frac` immigrants per pool; `sgd_prob` of the neural children are fine-tuned. Asset-set genes mutate with `asset_mutation_prob` via `assets::mutate_assets` over the latest `latent.crossprior.<ts>` proposals.

**Lifecycle (§6.4).** `candidate → holdout_passed → shadow → active → retired` (paper maps onto shadow/active, D-029), decided by the risk-engine's automatic pipeline — discovery from the orchestrator's final fronts (`fa-artifacts/strategies/<generation>.toml`), selection, one locked-holdout evaluation, admission into the managed live set `fa-artifacts/live/strategies.toml` (strategy-runtime reloaded via `ctl.strategy.reload`), gate-driven promotion/demotion/retirement; the full rules, gate items and tunables are in the [risk-engine README](../../bins/risk-engine/README.md) ("Strategy lifecycle" / "Strategy pipeline and holdouts"). Every transition is persisted in `ledger.strategy_state` and audited; baselines are never touched by the pipeline.

**Snapshot dependency (§6.5).** Strategies are bound to the encoder snapshot they were evolved on; region literals are remapped through region lineage on a swap (`remap` above), unmappable strategies are suspended, and the pipeline sends a strategy remapped after its promotion (or suspended) back to shadow. Parallel old-snapshot serving and shadow twins are implemented in [strategy-runtime](../../bins/strategy-runtime/README.md). `evo.vary.strategy` binds children to the generation's snapshot; `evo.eval.strategy` and the holdout replay score a bound genome on its own snapshot.

**Tunables (§7).** `gp_max_depth` 5 / `gp_max_nodes` 48 (`random::RandomSpec`); `step_eval_budget` `--step-budget-ms` 50; `min_share_per_repr` 0.3; `exposure_clip` [-1, 1]; `cost_stress_mult` 2.0; the pipeline values (`pbo_max` 0.2, `dsr_min_candidate` 0.95, `max_candidates_per_generation` 3, `holdout_min_dsr` 0.95 / `holdout_min_obs` 100, `max_live_evolved` 8, `max_shadow_days` 90 / `max_demotions` 2) live in `risk.toml [pipeline]`.

**Failure modes (§8).** Overfitting → deflated Sharpe, PBO gate, single-use locked holdout, live shadow. Look-ahead → all inputs through point-in-time replay, decoder outputs cached at publish time. NaN / out-of-range exposure → clipped to 0, flagged, repeated → strategy-runtime auto-pause (`--nan-limit`); the pipeline demotes an active evolved strategy and retires a shadow one. Step budget exceeded → step skipped (exposure unchanged), `--breach-limit` consecutive breaches → auto-pause. Broken snapshot/lineage → suspended to shadow until revalidated.

**Answered questions (§10).** GP programs are purely functional per step (state only via the portfolio primitives). Neural training is hybrid ES + an SGD fine-tune on the differentiable surrogate `mean[ln(1 + L·m·r) − c·|Δm|]` over an embargoed training window — no RL. GP and neural compute costs compare in one unit (estimated flops per asset-step, log10 scale). Decoder consumption is the latest fresh output per exact family and instrument, horizon-matched — no genome references. Exposures are relative to a notional sleeve the risk-engine scales. Region literals bind to a snapshot and remap through D-069 lineage.

**Deferred (§11).** Market-making / order-book-level strategies; strategies consuming raw text directly; cross-strategy communication / hierarchies.
