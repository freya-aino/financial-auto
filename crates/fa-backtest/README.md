# fa-backtest

Replay engine over archived streams through the live code path; validation statistics.

**Status:** implemented (v1) — deflated Sharpe, PBO (CSCV), ordered replay driver, `eval` (sequential point-in-time scoring of `fa-decoders` series decoders), **`replay`** (pipeline replay of `fa-strategies` programs with a virtual book and execution simulation), **`latents`** (recorded `LATENT` traffic replayed point-in-time into the same `LatentGraph` / `DecoderOutputs` the live runtime uses, D-059), **`cost`** (the paper venue's cost model, pinned to the broker-gateway fixture), **`validation`** (per-generation deflated Sharpe / PBO over a trial set) and **`allocator_replay`** (recorded strategy signals replayed through one allocator genome → netting → the same cost model: the allocator tournament's portfolio report). All tested. Encoders/MCMC are not re-run inside the replay (spec 41 §6.1): their **recorded outputs** are replayed instead, so a replay sees exactly what the live strategies saw.

## Strategy replay (`replay`)
Events are bar closes merged across instruments and ordered by `(close time, instrument)`; a bar is visible at its close. At every step: mark to market (equity point, per-step net return, funding/borrow carry), then the program decides for every instrument with `lookback_bars + 1` closes through `features::LiveContext` — the same context the live `strategy-runtime` builds — using only closes `≤ t`, its own virtual book (`position`, `unrealised_pnl`, `time_in_trade`) and, when a recording is supplied, the latent graph and decoder outputs **as of `t`**; each sleeve (`capital / n_instruments`) is filled at the close through `CostModel::price` (σ_day = lookback return std scaled to a day). Accounting is cash + mark-to-market, so `Δequity` is the net return and `Δequity + costs` the gross one. Identical spec + seed + data + recording → identical report (test).

### Recorded latents (`latents`, D-059)
`PipelineReplay::latents = Some(&RecordedLatents)` replays the `LATENT` stream's `latent.state.>` / `latent.region.>` / `latent.transition.>` / `decoder.output.>` messages (read by time with `fa_bus::replay::read_latents`) into a fresh `LatentGraph` + `DecoderOutputs` **incrementally**: before the decision at `t` only records published at or before `t` are ingested (knowledge time = server publish time), the graph view `LatentGraph::at(ts, t)` additionally filters on the messages' own `as_of ≤ t`, bar closes feed `record_close` for `region_feature`, and the decoder cache keeps the live default recency window (6 h). A latent published or dated after the step is never visible (test `a_latent_after_the_step_is_never_visible`). Every primitive call is counted by source — `EvalReport::sources{graph, decoder, fallback}`, also in `objectives()` as `sources.graph|decoder|fallback` (informational) — so a window predating the recordings is visibly fallback-only. `EvalReport::latents` reports what was fed (`fed{states, regions, transitions, decoder_outputs}`, `graph_rows`, `snapshot{declared, seen, mixed}`).

Snapshot consistency (spec 41 §4): `ReplaySpec::snapshot` declares the encoder snapshot; latents of the replay's timescale under another snapshot id are refused (`ReplayError::SnapshotMismatch`) unless `purpose == Diagnostic` (then `latents.snapshot.mixed = true`). An empty `snapshot` adopts the recording's. Decoder outputs are not latents and are not checked.

Fixture: `testdata/latent_fixture.jsonl` (540 records trimmed from the live stream on 2026-11-10 — 300 states, 60 region events, 120 transition rows, 60 decoder outputs; `fa_bus::replay::to_jsonl` format) drives `recorded_latents_feed_the_graph_deterministically` (identical report twice, `sources.graph > 0`, snapshot refusal / diagnostic acceptance). Regenerate with `FA_LATENT_FIXTURE_DUMP=1 cargo test -p fa-backtest -- --nocapture dump_fixture` against the compose NATS.

### Incremental recording cache (`latents::RecordingCache`, D-059 follow-up)
A cached recording covers a publish-time span. A requested window inside it is a **hit** (sliced, nothing read); a window overlapping or touching it is an **extend**: only `[start, cached start − 1]` and `[cached end − 5 s, end]` are read (the 5 s overlap picks up messages that reached the live edge after the previous read; duplicates are dropped by stream sequence), merged with `sort_records` and the covered span becomes the union; a disjoint window is a **miss** and replaces the recording. The budget counts messages over every recording: least recently used recordings are evicted first, a single oversized recording drops its oldest records (its covered start moves forward). Pure; the caller performs the reads (tests `recording_cache_extends_slices_and_evicts`, `latent_cache_decodes_slices_and_memoises`).

## Allocator replay (`allocator_replay`, spec 40 §6.2)
Per step of a 1 s grid over the window: signals published `≤ t` become visible (latest per strategy, alive for `signal_ttl_ms`, default 30 s like the risk-engine), the book is marked to the last close `≤ t` (per-step net return; each strategy that held a signal over the step feeds its realised return to the genome's `PerformanceTracker`), the genome's allocator weighs the live strategies, `net_targets_shrunk` nets them into EUR targets on the current equity and every instrument whose target moved by more than `min_trade_fraction · capital` trades at the close through `CostModel::price` (σ_day from the last 64 step returns). Identical spec + genome + data → identical report; `tournament` replays several genomes on identical inputs (spec 40 §9 "comparable paper P&L"). Objectives: `deflated_sharpe` (max), `sharpe` (max), `max_drawdown` (min), `turnover` (min), `concentration` = mean Herfindahl of |targets| (min), `cost_share` (min); informational `psr`, `n_trades`, `n_obs`, `n_strategies`, `mean_gross`, `max_weight`. The report also carries `mean_weights` per strategy, the equity curve and per-step returns.

Fixture: `testdata/signal_fixture.jsonl` (400 records of the live `SIGNAL` stream, 2026-11-10, 7 strategies) with SYNTHETIC random-walk marks drives `replay_on_the_fixture_is_deterministic_and_comparable`; regenerate with `FA_SIGNAL_FIXTURE_DUMP=1 cargo test -p fa-backtest -- --nocapture dump_signal_fixture`. `signals_after_the_step_are_invisible_and_ttl_expires` checks knowledge-time visibility and the TTL on a synthetic signal.

## Strategy replay objectives
Objectives (`EvalReport::objectives`, directions in `replay::DIRECTIONS`): `deflated_sharpe` (max; PSR vs the expected max Sharpe of `n_trials` trials — with one trial, PSR vs 0), `sharpe` (max), `max_drawdown` (min), `turnover` (min), `cost_sensitivity` = `sharpe − sharpe under 2× costs` (min), `compute_cost` = log10 program nodes per step (min); informational `calibration` (corr of emitted `std` with the next |return|), `cost_share`, `psr`, `n_trades`, `n_obs`, `sources.graph`, `sources.decoder`, `sources.fallback`. The report also carries the equity curve, per-step returns and the per-trade log (fill price, fee, slippage bps).
